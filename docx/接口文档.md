# 接口文档

> 本文件是所有「代码设计实现文档」的接口对照基准。
> 状态：**骨架（记录现状，待按 MVP 口径修订）**
> 最后更新：2026-09-26

## 相关基准

| 内容 | 位置 |
|---|---|
| 数据模型（表结构唯一事实来源） | `docx/database/schema.sql` + `docx/database/数据库设计.md` |
| 接口设计规范 | `.codebuddy/skills/api-design/SKILL.md`（资源名词 URL、`/api/v1` 前缀、camelCase 字段、统一错误体、分页元数据） |
| 范围与业务口径 | `docs/mvp-scope.json` |

约定要点（来自 api-design 技能，`feat-004` 落地时必须遵守）：

- 资源用名词复数：`GET /api/v1/guides`、`POST /api/v1/orders`
- 字段一律 camelCase（DB 用 snake_case，转换在后端）
- 列表接口带分页元数据；沿用现有 `pageNo / pageSize` 入参与 `{ list, total }` 返回
- 错误统一为 `{ "error": { "code": "...", "message": "...", "details": [] } }`
- 状态码：200 成功 / 201 创建 / 400 参数错 / 401 未登录 / 404 不存在 / 500 服务端错误

## 1. 调用约定

| 项 | 约定 |
|---|---|
| 数据层位置 | `api/index.js`（唯一出口，页面不得直连数据源） |
| mock 开关 | `const useMock = true`（MVP 阶段固定为 true） |
| 平台分支 | `// #ifdef MP-WEIXIN` 走 `wx.cloud`，其余平台走 mock |
| 分页参数 | `pageNo`（从 1 开始）、`pageSize`（默认 10） |
| 分页返回 | `{ list, total }` |
| 登录态 | `uni.getStorageSync('token')` |

## 2. UserApi

| 方法 | 入参 | 返回 | 现状 |
|---|---|---|---|
| `getCurrentUser()` | 无 | `{ _id, nickname, avatar, isAdmin } \| null` | mock：有 token 即返回测试用户 |
| `getUserInfo()` | 无 | 同 `getCurrentUser` | 别名 |
| `saveUserInfo(userInfo)` | 用户字段 | `_id \| null` | mock 返回 `'u1'` |
| `isAdmin()` | 无 | `boolean` | 判断 `isAdmin === true` |
| `wxLogin(params)` | `{ code, encryptedData, iv }` | `{ token, openid, userInfo }` | mock 返回 `mock_token_<时间戳>` |
| `logout()` | 无 | `true` | 清除 token |

## 3. ClerkApi（MVP 将改造为 GuideApi）

| 方法 | 入参 | 返回 |
|---|---|---|
| `getClerkList(params)` | `{ pageNo, pageSize, sex, city, categoryId, keyword }` | `{ list, total }` |
| `getClerkDetail(clerkId)` | 达人 id | 达人对象 \| null |
| `createClerk(clerkInfo)` | 达人字段 | 新 id |
| `updateClerk(clerkId, clerkInfo)` | id + 字段 | 无 |
| `getPendingClerks(pageNo, pageSize)` | 分页 | `{ list, total }`（`status: 0`） |
| `auditClerk(clerkId, status)` | id + `0/1/2` | 无 |

现有达人字段（mock 数据）：`_id, nickname, avatar, sex(1男/2女), city, price, orderCount, onlineStatus, skills[], introduce`。

## 5. AppointmentApi（MVP 将改造为 OrderApi，并升级为四态）

| 方法 | 入参 | 返回 |
|---|---|---|
| `createAppointment(appointInfo)` | 预约字段 | 新 id |
| `getMyAppointments(params)` | `{ pageNo, pageSize, status }` | `{ list, total }` |
| `getAllAppointments(params)` | `{ pageNo, pageSize, status, clerkId, appointDate }` | `{ list, total }` |
| `cancelAppointment(appointId)` | id | 无（`status = 2`） |
| `completeAppointment(appointId)` | id | 无（`status = 1`） |

**现有状态语义（3 态，与 MVP 不兼容）**

| status | 含义 |
|---|---|
| 0 | 待服务 |
| 1 | 已完成 |
| 2 | 已取消 |

**MVP 目标语义（4 态，见 `docs/mvp-scope.json`）**

| status | key | 含义 |
|---|---|---|
| 0 | pending-confirm | 待确认 |
| 1 | confirmed | 已确认 |
| 2 | completed | 已完成 |
| 3 | cancelled | 已取消 |

现有预约字段：`clerkId, goodsId, goodsName, date, timeSlot(morning/afternoon/evening), price, remark, status, createTime`。
