# BUG 修复：筛选 chip 被压缩竖排换行 + 「今日订单」恒为 0

- 日期：2026-09-26
- 严重级别：中（功能可用，但后台筛选项几乎没法点，统计条有一个数永远为 0）
- 发现方式：用户反馈「订单管理分类显示有问题」（截图）
- 相关：`pages/admin/appointment.vue`、`pages/guide/list.vue`、`pages/index/index.vue`、`api/mock/generate.js`

## 1. 现象

订单管理页顶部筛选行里，「全部日期」「全部状态」以及四个状态 chip 全部被**压成细长竖条**，文字逐字换行（「待确认」变成两行竖排）；同一行的「今日订单」统计恒为 `0`，地陪端接单页的「今日完成」同样恒为 `0`。

## 2. 复现步骤

1. 「我的」页切到管理员 → 进入订单管理
2. 观察筛选行：chip 竖排换行、宽度被挤压（见用户截图）
3. 观察统计条：「今日订单」永远是 0（无论数据多少）
4. 首页的区域页签、地陪列表页的 chip 有同样风险（同一套实现）

## 3. 根因

### 3.1 chip 竖排换行：flex 子项默认会被压缩

筛选行是横向滚动容器里的 `display: inline-flex` 行，chip 是它的 **flex 子项**。flex 子项默认 `flex-shrink: 1`，当行宽超过滚动容器可视宽度时，浏览器/小程序会把子项**压窄**而不是让容器溢出 —— chip 宽度被压到只剩一个字宽，文字于是竖向换行。

`scroll-view` 上的 `white-space: nowrap` 只作用于**文本的空白处理**，管不了 flex 子项的收缩，所以之前写了也没用。

### 3.2 「今日订单 / 今日完成」恒为 0：生成器把订单全排在明天之后

`api/mock/generate.js` 里所有订单的 `appointDate` 都是 `baseTime + rnd.int(1, 14)`（明天到两周后），而两个统计的口径是「约在**今天**的单」：

- 后台 `counts.todayAppoint`：`order.appointDate === formatDate(new Date())`
- 地陪端 `counts.todayFinished`：`status === 已完成 && appointDate === 今天`

因此这两个数在 mock 里**结构性恒为 0** —— 不是接口算错，是数据里根本没有「今天的单」。原型 07 屏画的是「今日订单 5」，说明设计上是有今天的单的。

## 4. 修复方案

### 4.1 chip / 页签不许被压缩（3 个页面）

```scss
.chip { flex: none; white-space: nowrap; ... }
.chip__text { white-space: nowrap; }
.tabline__item { flex: none; white-space: nowrap; }   /* 首页区域页签同病 */
.tabline__text { white-space: nowrap; }
```

- `pages/admin/appointment.vue`：`.chip` / `.chip__text` + 新增 `.chip-picker { flex: none }`（包住日期 chip 的 `<picker>` 也是 flex 子项）
- `pages/guide/list.vue`：`.chip` / `.chip__text`
- `pages/index/index.vue`：`.tabline__item` / `.tabline__text`

### 4.2 生成器补「约在今天」的订单

```js
// 每 5 单里有 1 单约在「今天」：否则「今日订单」（后台）与「今日完成」（地陪端）
// 两个统计会结构性恒为 0，演示时看起来像坏了
const appointDate = index % 5 === 0 ? formatDate(baseTime) : formatDate(addDays(baseTime, rnd.int(1, 14)));
```

16 单 → 4 单约在今天，两个统计都有意义（实测今日订单 4）。

### 4.3 门禁补覆盖

`scripts/smoke-flow.mjs` 新增断言「后台『今日订单』统计不为恒 0」—— 这类"数据里压根没有"的问题之前没有任何门禁会报。

## 5. 改动文件

- `pages/admin/appointment.vue` — chip 与 picker 加 `flex: none` / `nowrap`
- `pages/guide/list.vue` — chip 加 `flex: none` / `nowrap`
- `pages/index/index.vue` — 区域页签加 `flex: none` / `nowrap`
- `api/mock/generate.js` — 每 5 单 1 单约在今天
- `scripts/smoke-flow.mjs` — 新增「今日订单不为恒 0」断言
