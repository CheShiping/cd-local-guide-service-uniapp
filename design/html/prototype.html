色板（M3 色彩角色）

primary container surface tertiary on-surface outline
  • 竹青 #2f6b5e 只做一件事：可点的东西和选中态
  • 朱砂 #b4462f 是 M3 的 tertiary 角色，全站只给价格与关键数字
  • 宣纸 #f7f4ed 替代纯白，是"文化感"最省成本的一招
  • 状态色（竹青 / 姜黄 / 朱砂 / 灰）全部落进同一体系，不套系统绿橙红

图片策略

  • 图片来自后端：景点 coverUrl、地陪 avatarUrl，由接口返回完整 URL 后解析渲染
  • 原型阶段用网络占位图（picsum.photos / i.pravatar.cc），后端接通后直接换 URL，尺寸与样式不变
  • 固定容器 + aspectFill：容器尺寸写死、图片裁切填充，不用自绘插画或几何 SVG 冒充照片
  • 兜底：字段为空或加载失败时露出 primary-container 底色，不出现破图或拉伸
  • 仍然不吃体积的部分：零字体文件（系统宋体栈 + 字距）、零图片纹理（宣纸颗粒是 CSS 径向点阵）

迁移到 uni-app 的注意点

  • 类名与原工程同构：.status-bar .navbar .tabbar 可直接沿用，减少一次改名
  • 小程序端把 inset / color-mix / backdrop-filter 换成普通声明，避免低版本不识别
  • 图标用 SVG 时建议改成本地 .svg 或图标字体，小程序 <use> 支持有限
  • 底部 tabBar 现在只有 2 项，Material 建议 3-5 项；MVP 保持 2 项，后续可加「订单」
  • 触摸目标全部 ≥ 44px，列表行 ≥ 56px，符合 M3 与微信规范
